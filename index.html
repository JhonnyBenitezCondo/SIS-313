Como subir un proyecto a GitHub

Introduccion

GitHub permite almacenar nuestros proyectos de forma remota y trabajar con ellos utilizando Git.

  1. Crear una carpeta

    Crear una carpeta para el proyecto y abrir la terminal dentro de ella.

  2. Inicializar Git

    Iniciar el repositorio local y comprobar su estado.

    • git init
    • git status
  3. Preparar los archivos

    Agregar los archivos para realizar el commit.

    • git add .
  4. Crear un commit

    Guardar los cambios en el historial.

    • git commit -m "Primer commit"
  5. Crear el repositorio

    Ingresar a GitHub, seleccionar New repository, colocar un nombre y crear el repositorio.

  6. Conectar con GitHub

    Conectar el repositorio local con el repositorio remoto.

    • git remote add origin URL_DEL_REPOSITORIO
  7. Subir el proyecto

    Enviar el proyecto a GitHub.

    • git branch -M main
    • git push -u origin main
  8. Verificar

    Ingresar al repositorio y comprobar que los archivos se hayan subido correctamente.
